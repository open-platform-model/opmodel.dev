## Context

The site reads one docs bundle per source project. The controller's is keyed `opm-operator` in `site/bundles.cue`; the key is the GHCR path `docs/<key>`, and `repo:` is the only repository allowed to sign it (`opm-docs pull` compares it to the certificate's SourceRepositoryURI). v1.0 takes `pinned` projects at the versions the cli bundle's `manifest.json` `pins` names. After the rename, every new controller bundle is `docs/opm-controller`, signed by `open-platform-model/opm-controller`, and the cli pins it under that key. A pure name change: no page, mount or check is added or removed.

## Goals / Non-Goals

**Goals:**

- v1.0 and the edge build read `opm-controller` and fail exactly as before on a missing or mis-signed bundle.
- Every site-owned string that names the product says "controller"; the figures stay legible at the longer label.

**Non-Goals:**

- Redirects from the old URLs (owner decision: no aliases, no traces).
- Editing any source repository's pages (Principle I).

## Decisions

### 1. Exact names only, never a bare `operator` rule

Rename `opm-operator` (project, repository, tree) and the product noun. Keep the persona "Platform Operator" (`AGENTS.md`, `CONSTITUTION.md`), the CUE operator in `site/assets/css/opm/base.css`, and vendored files (`site/assets/lib`, `site/themes`). The footer label for tree `opm-controller` is `controller`.

### 2. Fixtures move, their numbers stay

`git mv` both fixture trees to `opm-controller/` and the two pages to `the-fixture-controller.md` and `controller-resources.md`; manifests follow (`project`, `source.repo`, `placement.owns`, `pages[].path/source/edit`). Versions (`1.0.0-beta.7`), commits and dates stay: they are fixture data, not release facts. The lock is regenerated by the same all-local pull `test-site.sh` runs (`catalogs/fixture-pull` fails on any drift). `opm-controller` sorts after `opm`, so every literal list in `test-site.sh` keeps its order and only the string changes.

### 3. Figure geometry

Measured with Geist's metrics (fontTools, 2026-10-05):

```text
three-ways-to-deploy  tool card 92 wide, 12px/600 "OPM controller" = 89.3   (was 82.2)   -> overflows
                      record card 104 wide, 10px mono "owner: controller" = 102.0 (was 90.0) -> overflows
where-things-live     10.5px mono "OPM controller" = 88.2, right-aligned at x=339; the line at x=252 is in its way
module-to-cluster     11px "the OPM controller" = 97.9 from x=186: fits (nothing to its right)
```

`three-ways-to-deploy` stays 360 wide: the tool card sets "OPM" and "controller" on two lines above "in the cluster" (the CLI row keeps two lines), and the outer margins drop from 8 to 4 so the record card can grow to 116 wide for `owner: controller`: start 4..124 (was 8..132), tool 136..228 (92 wide, as before), record 240..356 (was 248..352); the zone labels move with their columns. A first draft widened the figure to 380 instead; at a 390 px phone its 10px labels rendered at 9.0 px, under the 9 px floor `task shots` checks (measured offline in the QA image on the test-site fixture build), so it was redrawn; now 9.5 px, as in every other figure. `where-things-live` sets "OPM" and "controller" on two lines (y 338 and 352) above "fetches". `module-to-cluster` keeps its geometry. The figures are re-checked with `task shots` (light, dark, phone width) before merge.

### 4. The frozen lock

The cli release that pins `opm-controller` breaks main's pull until this change merges, and this change cannot pass before that release exists. A committed `site/bundles.frozen.json` (the documented recovery) is landed on main before the release; a cutover commit on this branch (`chore(site): drop the frozen bundle lock`) deletes it.

## Risks / Trade-offs

- [A redrawn label collides at some viewport] -> `task shots` before merge (light, dark, phone width); every figure keeps its 360 width, so phone text stays at 9.5 px.
- [A source bundle still links an old controller URL] -> the site's link check fails the build; the links are fixed in opm and cli, released before this change builds (proposal Impact).
- [`shots.py` skips a missing page silently] -> read the screenshot list: `reference/controller/` and `reference/controller/moduleinstance/` must appear in `site/.shots/`.

## Durable decisions

- The controller's docs project is `opm-controller`, signed by `open-platform-model/opm-controller`: lands in `site/bundles.cue`, `README.md` and `AGENTS.md`.
- The product is "the controller"; the persona "Platform Operator" stays: stays with the change (the workspace vocabulary rule lives in the enhancements repo).
