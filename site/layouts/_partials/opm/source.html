{{- /* Where a page's source lives: {key, repo, path, editURL, viewURL, ref, refText}, or an empty dict for a page with no content file. A file under //docs/site/ (in a normal build /src//docs/site/, for an anchored or a line version .versions///docs/site/) belongs to that repo, found from the /docs/site/ path segment, so archives, fixture roots and test copies map the same way. Any other content file is site-owned: opmodel.dev, site/content/. The key matches data/opm/lastmod.json. viewURL is set only when the page's version is anchored or line (data/opm/build.json, from site/versions.conf), never from the version name, which is no git ref. An anchored version points at the ref it resolved for the repo, a tag or a SHA. A line version points at the SHA of the tree it archived, since a branch it read moves; refText is the ref when that tree is the tag itself (docs "tag"), else the SHA. refText shows a SHA as seven hex characters. "Edit" goes where a fix to that tree lands: in a line version the branch the docs came from (main or release/...), otherwise main. A page of the Enhancements section names its file in the enhancements repository (repoPath) instead: viewURL at the commit the section was built from (data/opm/build.json's sections.enhancements), when the build names one, and no editURL, since an entry changes through its own review, not a page edit. Its key is empty: its date is the entry's updated date, not a git date. A page of the Catalogs section names the file its bundle says it came from (params.catalog.source) in the catalog's repository, viewURL at the commit the bundle was built from, and no editURL: an edit lands on main and reaches a released minor only through a docs revision. A page without a source gets no link. Its key is empty: its date is the manifest's lastmod (the page's Lastmod). */ -}} {{- $out := dict -}} {{- if eq .Section "catalogs" -}} {{- $c := .Params.catalog | default dict -}} {{- $view := "" "") (printf "%s/blob/%s/%s" $base $sha .Params.repoPath) "") "ref" $sha "refText" (cond (ne $sha "") (substr $sha 0 7) "") -}} {{- end -}} {{- with .File -}} {{- $fn := replace .Filename "\\" "/" -}}
