{{- /* Where a page's source lives: {key, repo, path, editURL, viewURL, ref, refText}, or an empty dict for a page with no content file. A page of a docs bundle (a file under /_versions///content/, mounted by gen-mounts.sh; docs-kit C15, C16), which is every page of a version outside site/content/, takes its data from the bundle's manifest, through data/opm/docs-bundles.json (gen-docs-bundles.sh), per docs-kit C8: editURL https://github.com//edit/main/ when the page has edit (an authored page whose file main still has; never a generated one), shown on every version, since the link names main, where a fix lands (docs-kit DESIGN decision 19); viewURL the page's source at source.commit, when it has one, named by the release tag (source.ref; an edge build by its commit); lastmod the manifest's, or none. Its key is empty: its date is not a git date. "bundle" is true. A page of the Enhancements section names its file in the enhancements repository (repoPath) instead: viewURL at the commit the section was built from (data/opm/build.json's sections.enhancements), when the build names one, and no editURL, since an entry changes through its own review, not a page edit. Its key is empty: its date is not a git date but the bundle's (the entry's updated date on its own page, the manifest's lastmod on a document). A page of the Catalogs section names the file its bundle says it came from (params.catalog.source) in the catalog's repository, viewURL at the commit the bundle was built from, and no editURL: an edit lands on main and reaches a released minor only through a docs revision. A page without a source gets no link. Its key is empty: its date is the manifest's lastmod (the page's Lastmod). Any other content file is site-owned: opmodel.dev, site/content/, editURL on main, no viewURL; its key matches data/opm/lastmod.json (gen-site-dates.sh). */ -}} {{- $out := dict -}} {{- if eq .Section "catalogs" -}} {{- $c := .Params.catalog | default dict -}} {{- $view := "" -}} {{- if and $c.source $c.repo $c.commit -}}{{- $view = printf "https://github.com/%s/blob/%s/%s" $c.repo $c.commit $c.source -}}{{- end -}} {{- return dict "key" "" "repo" ($c.repo | default "") "path" ($c.source | default "") "editURL" "" "viewURL" $view "ref" ($c.commit | default "") "refText" (cond (ne $view "") (substr $c.commit 0 7) "") -}} {{- end -}} {{- if and (eq .Section "enhancements") .Params.repoPath -}} {{- $sha := "" -}} {{- with hugo.Data.opm -}}{{- with .build -}}{{- with .sections -}}{{- with .enhancements -}}{{- $sha = .sha | default "" -}}{{- end -}}{{- end -}}{{- end -}}{{- end -}} {{- $base := printf "%s/enhancements" site.Params.opm.github -}} {{- return dict "key" "" "repo" "enhancements" "path" .Params.repoPath "editURL" "" "viewURL" (cond (ne $sha "") (printf "%s/blob/%s/%s" $base $sha .Params.repoPath) "") "ref" $sha "refText" (cond (ne $sha "") (substr $sha 0 7) "") -}} {{- end -}} {{- with .File -}} {{- $fn := replace .Filename "\\" "/" -}} {{- with findRESubmatch `/_versions/(v[0-9]+\.[0-9]+)/([a-z0-9]+(?:-[a-z0-9]+)*)/content/(.+)$` $fn 1 -}} {{- $m := index . 0 -}} {{- $b := dict -}} {{- with hugo.Data.opm -}}{{- with index . "docs-bundles" -}}{{- with .versions -}}{{- with index . (index $m 1) -}}{{- with index . (index $m 2) -}}{{- $b = . -}}{{- end -}}{{- end -}}{{- end -}}{{- end -}}{{- end -}} {{- if not $b.repo -}}{{- errorf "opm/source.html: %s is in no docs bundle data/opm/docs-bundles.json lists for %s" $fn (index $m 1) -}}{{- end -}} {{- $p := index $b.pages (index $m 3) | default dict -}} {{- $edit := "" -}} {{- with $p.edit -}}{{- $edit = printf "https://github.com/%s/edit/main/%s" $b.repo . -}}{{- end -}} {{- $view := "" -}} {{- with $p.source -}}{{- $view = printf "https://github.com/%s/blob/%s/%s" $b.repo $b.commit . -}}{{- end -}} {{- $refText := cond (and $b.ref (ne $b.version "edge")) $b.ref (substr $b.commit 0 7) -}} {{- $out = dict "key" "" "repo" $b.tree "path" ($p.source | default "") "editURL" $edit "viewURL" $view "ref" $b.commit "refText" $refText "lastmod" ($p.lastmod | default "") "bundle" true -}} {{- end -}} {{- end -}} {{- if $out.bundle -}}{{- return $out -}}{{- end -}} {{- with .File -}} {{- $path := printf "site/content/%s" (replace .Path "\\" "/") -}} {{- $out = dict "key" (printf "opmodel.dev/%s" $path) "repo" "opmodel.dev" "path" $path "editURL" (printf "%s/opmodel.dev/edit/main/%s" site.Params.opm.github $path) "viewURL" "" "ref" "" "refText" "" -}} {{- end -}} {{- return $out -}}
