{{- /* OPM override of Hextra's render-link.html (v0.13.0, pinned in overrides.sha256). Every internal link resolves through the current version's page tree, and a miss fails the build (check Q1). Source pages write root-absolute links (/docs/
//), which become //docs/... here; a file-relative link (what cobra's GenMarkdownTree writes) resolves against the page's directory. External (scheme), #fragment and mailto: links pass through.
